# 文档目录

第一次接触 fx-CG50 第三方程序时，建议先阅读仓库首页的完整教程，再按需要进入下面的专题。

## 从零开始

1. 阅读 [`README.md`](../README.md)，理解 `.g3a`、PythonExtra 与原生 C 的关系。
2. 运行 [`keytest_v2.py`](../examples/key-test/keytest_v2.py)，确认 PythonExtra、绘图与按键输入正常。
3. 运行 [`mario_cg50_v3.py`](../examples/mario/mario_cg50_v3.py)，观察游戏循环、碰撞、滚屏和状态机。
4. 阅读移植专题，理解怎样把 PC 开源小游戏适配到 fx-CG50。
